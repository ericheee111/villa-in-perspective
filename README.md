# 别墅 · 空间漫游

三层别墅的交互式设计浏览网页，基于 v35 最新工程导出。

**在线访问：https://ericheee111.github.io/villa-in-perspective/**

## 使用

- 切换负一层、一层和二层。
- 拖动旋转，滚轮缩放，右键平移；也支持触摸操作。
- 使用房间按钮定位空间，或进入对应室内机位。
- 切换墙体剖切、平面布局、日夜氛围与 v35 效果图。

模型按楼层加载，首次进入需要下载模型文件。网页材质经过轻量化，精细装修效果请对照渲染图。

## 发布

纯静态站点，无后端或 ChatGPT 运行依赖。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 保留原始静态文件。

本地预览：在仓库目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。
