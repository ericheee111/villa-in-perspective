# 别墅 · 空间漫游

三层别墅的交互式设计浏览网页，基于 v35 最新工程导出。

**在线访问：https://ericheee111.github.io/villa-in-perspective/**

## 使用

- 默认显示三层总览，三层按原坐标与标高拼合；可单独查看负一层、一层和二层。
- 拖动旋转，滚轮缩放，右键平移；也支持触摸操作。
- 使用房间按钮定位空间，或进入对应室内机位。
- “随视角”墙体模式保留远侧完整墙面，让近侧上部墙体退让；“完整”模式恢复墙体。
- 点击门扇开合，点击房间标签旁的灯泡开关灯；侧栏提供各空间与批量控制。共有 20 组门、25 个灯光回路，对应原场景的 90 盏灯具。
- 开关状态在本次浏览和楼层切换中保留；夜间模式更容易观察灯光效果。
- “楼梯连通”聚焦两段楼梯，金色线标出路线；二层到层平台补充衔接板。
- “查看外观”显示暖白墙面、简洁平屋顶、灰绿金属雨棚与屋顶楼梯出入口的临时方案，等待实景照片更新。
- 平面布局使用单层正上方视图；从总览切换平面时默认进入一层。v35 设计效果图保持静态。

模型按楼层加载，首次总览需加载三层模型。网页材质经过轻量化，灯具以空间回路控制，每个空间使用一个实时近似光源，精细装修效果请对照渲染图。

总览保持原 v35 楼层坐标；平台衔接与外观是可单独修改的网页附加模型，原 `.blend` 未被覆盖。附加尺寸和配色位于 `model/overview.json`，几何生成与视角剖切位于 `house-view.js`。保留旧模型二进制文件以兼容旧页面缓存。

## 发布

纯静态站点，无后端或 ChatGPT 运行依赖。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 保留原始静态文件。

本地预览：在仓库目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。
